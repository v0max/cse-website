## Content

All site content is data in `content/` (see MAINTAINING.md); pages are generated
from it by `src/lib/content.ts`. Add or change people, cases and site text there,
not in components. Portraits in `public/portraits/` are generated by
`tools/portraits/build.py`; never edit them by hand.

Wherever a page lists the experts on a case, matter or practice area, render
the names with `<ExpertLinks>` (`src/ui/Chrome.tsx`) so each name links to that
person's profile. All styles live in `src/app/globals.css`, ordered to match the
page; keep the comment above each rule saying where on the page it is used.
